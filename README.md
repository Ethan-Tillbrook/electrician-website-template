Electrician Business Website
A responsive business website built from scratch for a local electrician client
using HTML and CSS — my first end-to-end client project.
About
This project was built for a real business need, translating initial requirements
into a functional, mobile-friendly website without the use of any frameworks or templates.
Features

Fully responsive layout using CSS Flexbox and Media Queries
Service listings and contact form
Clean, professional design optimized for small business use

Built With

HTML5
CSS3
Git / GitHub
